offmerg.py is a python file that gets offsets from three sites.
the sites being this:
https://getvexor.fyi/offsets.hpp
https://offsets.imtheo.lol/
https://offsets.credosdev.lol/
credits to all three of them.
uses four args, --export-json, --export-c++, --export-conflicts, --export-source
--export-json only spits out the json versions of the offsets (.json)
--export-c++ only spits out the c++ versions of the offsets (.h)
--export-conflicts exports the amount of conflicts, essentaily offsets with the same name but different values
--export-source exports the amount of total offsets and how many offsets came from what website
